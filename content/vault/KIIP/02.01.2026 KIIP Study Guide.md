### GRAMMAR ANALYSIS  
**~(으)ㄴ 곳이에요 (Chapter 1)**  
- Meaning and usage: Describes a place with a specific quality. Attach ~(으)ㄴ to adjective stem, then 곳이에요. Use for introducing hometowns or locations (e.g., 공기가 깨끗한 곳이에요 - a place with clean air).  
- Restrictions: Only for adjectives; cannot use with verbs. Not for people or actions.  
- Common learner mistakes: Forgetting (으) if stem ends in consonant (e.g., 아름다운 곳, not 아름다운). Mixing with ~는 곳 (which is for ongoing actions).  
- Connect to KIIP Level 1: Builds on basic adjective conjugation from Level 1 (e.g., ~아요/어요) to form relative clauses for descriptions.  

**~(으)ㄹ게요 (Chapter 2)**  
- Meaning and usage: Expresses speaker's intention or mild promise for future. Attach to verb stem (e.g., 내가 청소할게요 - I'll clean). Informal, polite.  
- Restrictions: Only for first-person intentions; not for questions or third-person. Cannot use with past tense.  
- Common learner mistakes: Using with adjectives (wrong; adjectives use ~게 될 거예요). Confusing with ~겠어요 (stronger will).  
- Connect to KIIP Level 1: Extends future ~아/어 볼게요 from Level 1 trials to personal commitments.  

**~아/어 보세요 (Chapter 3)**  
- Meaning and usage: Polite suggestion to try an action. Attach to verb stem (e.g., 신어 보세요 - try putting on). Common in shopping or advice.  
- Restrictions: Imperative form; not for statements. Use with actions, not states.  
- Common learner mistakes: Omitting ~세요 for politeness (e.g., ~아/어 봐 wrong in formal). Confusing with ~아/어 보다 (to try and see result).  
- Connect to KIIP Level 1: Builds on basic imperatives ~세요 to add trial nuance.  

### VERB & ADJECTIVE SYSTEMS  
**Base form → changed form step by step**  
- Regular: Add endings directly (e.g., 가다 → 가요).  
- Irregular groups:  

**으-irregular (ㅡ stems)**  
- Group: Similar for memorization as vowel drop.  
- Step: Drop ㅡ if ending starts with 아/어 (e.g., 예쁘다 base → 예쁘 → 예뻐요). If consonant ending, keep ㅡ (e.g., 예쁩니다).  
- Examples: 크다 → 커요 (big), 쓰다 → 써요 (bitter).  

**ㄹ-irregular**  
- Group: Stems ending in ㄹ.  
- Step: Drop ㄹ before ㄴ/ㅂ/ㅅ endings (e.g., 만들다 → 만드는). Keep ㄹ otherwise (e.g., 만들어요).  
- Examples: 살다 → 사는 (living), 알다 → 아는 (knowing).  

**ㅂ-irregular**  
- Group: Stems ending in ㅂ.  
- Step: Change ㅂ to 우 before vowel (e.g., 돕다 → 도와요). For consonant, regular (e.g., 돕습니다).  
- Examples: 춥다 → 추워요 (cold), 맵다 → 매워요 (spicy).  

**ㄷ-irregular**  
- Group: Stems ending in ㄷ.  
- Step: Change ㄷ to ㄹ before vowel (e.g., 듣다 → 들어요). For consonant, regular (e.g., 듣습니다).  
- Examples: 걷다 → 걸어요 (walk), 묻다 → 물어요 (ask).

**Warning list of topics that cause problems in KIIP Level 2**  
- Irregular verbs: Forgetting changes (e.g., 듣다 not 들어요) leads to conjugation errors.  
- Batchim pronunciation: Mispronouncing finals (e.g., 맛 as 'mat' not abrupt 'mat') affects listening/speaking.  
- Vocab nuances: Confusing similar descriptions (e.g., 깨끗하다 vs. 한적하다).  
- Culture application: Trash rules often tested; mistakes in separation common for immigrants.
