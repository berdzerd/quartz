## About Berdzerd
I am a beginner developer who started learning C through [K&R's The C Programming Language](https://colorcomputerarchive.com/repo/Documents/Books/The%20C%20Programming%20Language%20%28Kernighan%20Ritchie%29.pdf). Setting up the environment to code has lead me down a rabbit hole including setting up [Asahi Linux](https://asahilinux.org/) on my M2 Macbook Pro, and later installing [Omarchy](https://omarchy.org/) on an older intel mac, which I have since set up to be a Home Server running services such as [Vaultwarden](https://github.com/dani-garcia/vaultwarden) for a password manager, and [Immich](https://immich.app/) for photo hosting. I look forward to continuing my journey by starting the [Odin Project](https://www.theodinproject.com/) to learn Javascript, and Harvard's [CS50x](https://cs50.harvard.edu/x/) to learn more about C and Python. 

I am also a teacher, artist and Korean Language learner. This garden will be a space where you can explore my thoughts, research and progress in development as well as various other interests.
