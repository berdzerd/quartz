Lesson 13 Words

| Korean    | English                                  | Example                 |
| --------- | ---------------------------------------- | ----------------------- |
| 편지를 보내다   | to send a letter                         | 친구에게 편지를 보내요.           |
| 편지를 부치다   | to mail a letter (at the post office)    | 우체국에서 편지를 부쳤어요.         |
| 국제 특급 우편  | international express mail               | 국제 특급 우편으로 보내면 빨리 도착해요. |
| 주소를 쓰다    | to write an address                      | 봉투에 주소를 써요.             |
| 소포        | parcel, package                          | 소포를 한국에서 미국으로 보내요.      |
| 택배        | delivery service (courier delivery)      | 택배로 물건을 받았어요.           |
| 등기        | registered mail                          | 중요한 서류를 등기로 보냈어요.       |
| 편지 봉투     | envelope                                 | 편지 봉투를 샀어요.             |
| 우편 번호를 쓰다 | to write a postal code                   | 우편 번호를 꼭 써야 해요.         |
| 우표를 붙이다   | to attach a stamp                        | 우표를 봉투에 붙였어요.           |
| 계좌를 개설하다  | to open a bank account                   | 은행에서 계좌를 개설했어요.         |
| 통장을 만들다   | to make a bankbook (open a bank account) | 통장을 만들려고 은행에 갔어요.       |
| 출금하다      | to withdraw money                        | ATM에서 돈을 출금했어요.         |
| 돈을 찾다     | to withdraw money (more casual/common)   | 은행에서 돈을 찾았어요.           |
| 돈을 보내다    | to send money                            | 부모님께 돈을 보냈어요.           |
| 송금하다      | to transfer money (formal)               | 해외로 돈을 송금했어요.           |
| 공과금을 납부하다 | to pay utility bills                     | 전기 요금을 납부했어요.           |
| 입금하다      | to deposit money                         | 은행에 돈을 입금했어요.           |
| 돈을 넣다     | to put money in (deposit, casual)        | 통장에 돈을 넣었어요.            |
| 돈을 바꾸다    | to exchange money                        | 공항에서 돈을 바꿨어요.           |
| 환전하다      | to exchange currency (formal)            | 은행에서 달러를 환전했어요.         |
| 신용 카드     | credit card                              | 신용 카드로 결제했어요.           |
| 체크 카드     | debit card                               | 체크 카드로 돈을 냈어요.          |
| 현금 자동 인출기 | ATM (cash machine)                       | 현금 자동 인출기에서 돈을 찾았어요.    |
